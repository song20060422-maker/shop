# .agents 目录说明（Agent 提示词版本管理）

本目录存放各 Agent 的提示词，按版本归档，**任何修改都不覆盖旧版**。

## 目录结构

```text
.agents/
├─ 00-index.md               # 约束文件目录（索引分文件与角色任务书）
├─ 01-business-rules.md      # 详细规则：技术栈边界、状态机、BR/E/INV、并发防御、实现模式
├─ 02-workflow-git.md        # 详细规则：工作项、提交规范、编号核验、门禁、交接
├─ 03-quality-security.md    # 详细规则：覆盖率、race、自检清单、红线
├─ 04-ops-rules.md           # 详细规则：配置部署、冲突裁决、缺陷修复
├─ agent-dev.md              # 开发 Agent 会话启动提示词全文（现役 v6.0，整体下发用）
├─ agent-test.md             # 独立测试 Agent 会话任务书（现役 v2.0）
├─ agent-acceptance.md       # 独立验收 Agent 会话任务书（现役 v2.0）
├─ README.md                 # 本文件：版本索引、加载记录、保留规则
└─ versions/
   ├─ dev-agent.v1.md        # v1.0 独立 shop-trading 项目基线（自 shop 仓库归档，未改动）
   ├─ dev-agent.v2.md        # v2.0 gin-vue-admin 结合版
   ├─ dev-agent.v3.md        # v3.0 需求驱动版（按 BR/E/S/AC/INV 绑定判据）
   ├─ dev-agent.v6.md        # v6.0 题面原文入版（v4/v5 为编号文件集与单文件合并，见 00-index.md，未单独归档全文）
   ├─ agent-test.v1.md       # 测试 Agent 任务书 v1.0（2026-11-12 实际下发版，2026-11-15 替换为 v2.0 后归档）
   └─ agent-acceptance.v1.md # 验收 Agent 任务书 v1.0（含 2026-11-11~12 验收逐项结论记录表，2026-11-15 替换为 v2.0 后归档）
```

## 保留与变更规则

1. 修改提示词时：先新增 `versions/<agent>.vN.md`，再更新 `dev-agent.md` 与上表，**禁止就地覆盖历史版本**。
2. 每次变更写明：改了什么、为什么改、对应哪个需求编号或工作项、是否经学生确认。
3. 提交格式：`[类型] [版本号] [编号] 描述`（依据仓库根 `commit-convention.md`：feat/fix 编号必填飞书工作项 `#数字` 并经 meegle 核验；工程内 T 编号取自 `docs/dev_log.md` 与之对应）。
4. 提示词不替代 `AGENTS.md`：约束冲突时以 `AGENTS.md` 为准（其中的旧提交格式条款待学生修订）。
5. 历史版本只读，不得删除；废止某版本时在上表标注“已废止 + 原因”。

## 与交付证据的对应

- 共同要求要求提交“约束文件历史版本、实际加载或读取记录及对应任务”：本目录的 `versions/` 与“加载记录”表即对应证据。
- 开发会话导出中应能定位到“何时加载了哪一版”，并与本表一致。
